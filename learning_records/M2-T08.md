## 1. 本任务目标

M2-T08 的目标是把前面通过 curl、Swagger、OpenAPI smoke test 和日志完成的人工验证，转换成可重复执行的 HTTP 接口自动化测试。

测试链路：

```text
pytest
→ FastAPI TestClient
→ ASGI application
→ middleware
→ FastAPI routing / Pydantic
→ Route
→ ProjectService
→ test-only InMemoryProjectStorage
→ exception handler / response model
→ HTTP Response
→ assert
```

与生产运行链路相比：

```text
生产：
HTTP socket
→ Uvicorn
→ FastAPI ASGI application

测试：
TestClient
→ FastAPI ASGI application
```

因此接口测试不需要先启动 Uvicorn，但仍然会经过 FastAPI application 的核心 HTTP 行为。

## 2. 测试隔离

本卡的重要设计不是只增加 `TestClient`，而是确保 API 测试不会修改真实：

```text
data/projects.json
```

测试使用：

```text
ProjectService
→ InMemoryProjectStorage
```

而正式应用继续使用：

```text
ProjectService
→ JsonProjectStorage
→ data/projects.json
```

测试 fixture 每次创建独立的 `InMemoryProjectStorage`，因此：

```text
Test A
→ Storage A

Test B
→ Storage B
```

而不是让多个测试共享真实持久化状态。

建立的原则：

```text
test isolation
测试独立
测试可重复
测试顺序无关
测试不污染开发数据
```

## 6. PATCH 回归保护

本卡最重要的行为测试之一：

```text
test_patch_project_preserves_unsent_fields
```

它保护 M2-T05 建立的 PATCH 语义：

```text
只发送 description
→ description 更新
→ name / tags / members 保持不变
```

如果测试只断言：

```python
assert response.status_code == 200
```

那么即使 Route 意外把：

```text
tags
members
```

清空，测试仍可能通过。

所以接口测试必须同时关注：

```text
status code
+
response body
+
业务状态变化
```

这把之前的手工验证正式转化成自动回归保护。

## 13. 本次发现的依赖告警

测试全部通过，但 pytest 输出中存在 2 条 deprecation warning。

### 13.1 Starlette TestClient / httpx

实际警告：

```text
StarletteDeprecationWarning:
Using `httpx` with `starlette.testclient` is deprecated;
install `httpx2` instead.
```

这不是 API 业务失败，也不是 M2-T08 测试逻辑失败。

当前 Starlette TestClient 已优先尝试 `httpx2`，如果没有安装才回退到 `httpx` 并发出该警告。

建议把 M2-T08 新增的 TestClient 开发依赖迁移到：

```toml
[project.optional-dependencies]
dev = [
    "pytest>=8,<10",
    "httpx2>=2.13,<3",
]
```

如果当前 `dev` 中有仅为 TestClient 添加的：

```toml
"httpx>=0.28,<0.29"
```

建议替换为 `httpx2`，而不是长期忽略该 warning。

注意：本次上传材料是在现有环境下执行的，因此正式记录只写：

```text
57 passed, 2 warnings
```

不会虚构“切换 httpx2 后 warning 已消失”的执行结果。

### 13.2 AnyIO alias warning

第二条：

```text
DeprecationWarning:
The anyio.abc.BlockingPortal alias is deprecated,
use anyio.from_thread.BlockingPortal instead.
```

来源位于：

```text
site-packages/starlette/testclient.py
```

而不是当前项目源码。

因此不建议在项目中：

```text
修改 site-packages
复制第三方代码
全局隐藏所有 DeprecationWarning
```

正确做法是：

```text
记录
→ 保持依赖可升级
→ 在兼容的 FastAPI / Starlette 版本中自然修复
```

这属于非阻断的依赖维护事项，不影响本次 M2 接口行为验收。

## 4. 主动 Bug 定位

实验故障：

```python

```

替换正确逻辑：

```python

```

定位思路：

```text
CLI args.tags 正常
→ run_command 传递正常
→ Service 入参正常
→ Project.tags 异常
```

## 7. 综合问答结论

Q1～Q10 整体通过。

两处技术修正：
1. `b = a` 后，应表述为“通过 `b` 对共享可变对象进行原地修改时，`a` 也能观察到变化”；重新绑定 `b` 不会自动修改 `a`。
2. 对现代 `dataclass`，`tags: list[str] = []` 通常会被 `dataclasses` 在类定义阶段直接拒绝并要求 `field(default_factory=list)`；共享可变默认值的风险概念本身理解正确。

### 4.2 SELECT / WHERE / ORDER BY

已实际验证：

``` sql
SELECT name, description
FROM m3_t01_projects;

SELECT name, description
FROM m3_t01_projects
WHERE name = 'alpha';

SELECT name, description
FROM m3_t01_projects
ORDER BY name;
```

确认能够：

``` text
读取多行
→ WHERE 筛选目标行
→ ORDER BY 明确排序
```

结果：✅

### 4.3 UPDATE

实际执行：

``` sql

SET description = 'Alpha updated in PostgreSQL'
```



结果：✅

### 4.4 DELETE

## 5. CRUD 完整闭环与安全结论

本卡已形成：

``` text
Create → INSERT alpha / beta
Read   → SELECT / WHERE / ORDER BY
Update → UPDATE alpha → SELECT 验证
Delete → DELETE beta  → SELECT 验证
```

写操作建立以下原则：

``` text
UPDATE / DELETE
→ 先确认 WHERE 的影响范围
→ 执行写操作
→ 再 SELECT 验证最终状态
```

没有 `WHERE` 的：

``` sql
DELETE FROM m3_t01_projects;
```

会作用于整张表；本卡没有用这种方式完成正常删除。

## 3. 核心概念结论

### Uvicorn 与 FastAPI

```text
Uvicorn
→ ASGI Server
→ 监听网络端口
→ 接收连接和 HTTP 请求
→ 按 ASGI 协议调用 Web application
→ 将响应发送回客户端

FastAPI
→ Web Framework
→ 定义和匹配路由
→ 调用对应 Python 函数
→ 处理请求与响应
→ 生成 OpenAPI Schema
→ 提供 Swagger UI
```

FastAPI 本身不是负责监听端口的网络服务器。

### `app.main:app`

```text
app.main:app
│   │    │
│   │    └── app/main.py 模块中的 app 属性
│   │        该变量引用 FastAPI application instance
│   │
│   └─────── main module，即 app/main.py
│
└─────────── app Python package
```

它可以近似理解为：

```python
from app.main import app
```

这里的 `main` 是 Python module，而不是原 CLI 的 `main()` 函数。

### 为什么启动 Web 服务时不会执行 CLI `main()`

原 CLI 保留：

```python
if __name__ == "__main__":
    raise SystemExit(main())
```

直接执行模块时：

```text
__name__ == "__main__"
```

CLI `main()` 会运行。

Uvicorn 导入 `app.main` 时：

```text
__name__ == "app.main"
```

因此 `if __name__ == "__main__"` 条件为假，CLI `main()` 不会执行。

这使同一个模块能够在当前过渡阶段同时保留 CLI 入口和 FastAPI application。

## 4. OpenAPI 与 Swagger UI

FastAPI 根据已经注册的路由生成 OpenAPI Schema：

```text
FastAPI routes
→ OpenAPI Schema
→ /openapi.json
→ Swagger UI
→ /docs
```

其中：

```text
/openapi.json
→ 机器可读的 API 描述

/docs
→ Swagger UI
→ 读取 OpenAPI Schema 后渲染出的交互式 API 页面
```

因此：

```text
OpenAPI ≠ Swagger UI
```

`/docs` 依赖 OpenAPI Schema；OpenAPI Schema 本身不依赖 Swagger UI。

## 7. 路由修改实验

验收过程中进行了路由变化观察。

临时将：

```python
@app.get("/")
```

修改为：

```python
@app.get("/hello")
```

随后实际请求结果为：

```text
GET /
→ 404 Not Found

GET /hello
→ 200 OK
```

`/hello` 返回：

```json
{
  "name": "AI Workspace Lite",
  "version": "0.1.0",
  "status": "ok"
}
```

该实验说明 FastAPI 根据已经注册的 Method + Path 进行路由匹配。

当只注册：

```text
GET /hello
```

时，请求：

```text
GET /
```

不会自动调用该函数，而是返回 404。

该修改属于学习实验，不属于预期最终提交状态；最终应恢复本任务的最小 `GET /` 路由。

最后一次完整 `42 passed` 的验证发生在临时路由修改之前，因此不虚构“恢复路由之后重新执行了测试”的结果。

## 8. 未实际执行实验的原理补全

命令：

```bash
python -m uvicorn app.main:not_app --reload
```

用于区分 Python module 查找与 attribute 查找。

执行逻辑：

```text
找到 app package
→ 找到 app.main module
→ import app.main 成功
→ 在 module 中查找 not_app
→ not_app 不存在
→ Uvicorn application 加载失败
```

因此该错误与：

```text
ModuleNotFoundError
```

不同。

应能区分：

```text
app.not_exist:app
→ module 不存在

app.main:not_app
→ module 存在，但目标 attribute 不存在

app.main:app
→ module 和 FastAPI application attribute 均存在
```

本实验未要求继续重复操作，概念验收通过。
